Authenticated Encryption with Associated Data (AEAD) is a technique used in cryptography which provides both the **encryption and authentication** and also associate additional data along with the encrypted message.

It encrypts sensitive data while simultaneously verifying that the data has not been altered and was generated by a party possessing the correct cryptographic key.

![](../assets/Pasted%20image%2020261010200231.png)


When considering only the Authenticated Encryption or AE, it has the ability to provide both confidentiality and integrity. But it is not capable of preventing replay attacks.

For this purpose, ‘AE’ adds associated data (AD) into the message to provide authenticity to the cipher text. With this additional data, if any modifications happened to the cipher text can be identified. 

Addresses, ports, sequence numbers, etc. can be included as associated data.

## How does AEAD work?

AEAD encrypts plaintext into ciphertext while generating an **authentication tag**, a cryptographic value used to verify data integrity and authenticity.

When the recipient receives the message, the AEAD algorithm verifies the authentication tag before accepting the data. If any part of the ciphertext or associated data has been modified, authentication fails and the message is rejected.

Associated Data remains visible but is still protected against tampering. Common examples include network packet headers, protocol information, timestamps, and routing metadata that must remain readable while still requiring integrity protection.
