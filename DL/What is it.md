Why DL is so good?

 - Highly applicable to several problems
 - High performance


In DL, we don't need to use feature engineering techniques. DL does representational learning, which means it can discover the features itself! For example- Lets try to classify images as DOg or cat. If we use ML, we need to create features, like size, color, etc.
