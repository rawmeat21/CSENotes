

**1. Supervised Learning**  

In this type, we have the input and output. The task of the program is to find a relation among them, such that when supplied with new data, the model can predict an output with good accuracy.

Two subtypes:

- _Classification_ — for categorical data
- _Regression_ — for numerical data

**2. Unsupervised Learning**  

We have input only. We can do:

- _Clustering_ (grouping similar points, e.g. customer segments)
- _Dimensionality reduction_ (PCA)
- _Anomaly detection_
- _Association rule based learning_

**3. Semi-supervised Learning**  

It is partially supervised and unsupervised. Example of use: We want to do supervised learning but we have a large amount of data. So we supply a few input-output pairs and predict the other outputs.

**4. Reinforcement Learning**  

An agent learns by interacting with an environment, getting rewards/penalties, learning happens through trial and error.
