### Batch Learning (Offline Learning)

- Trained on the **entire dataset at once**
- Once deployed, it doesn't learn further. To update it, we have to retrain from scratch on old + new data
- Needs significant compute/time, usually done offline
- Problem: Model never learns anything new. Also we need to retrain periodically with new data.

When to use: Image classification, anything where concept doesn't change much

### Online Learning

- Trained **incrementally**, feeding data in small groups (mini-batches) or one instance at a time
- Learns continuously and adapts quickly to new patterns. Gets better the more its used.
- Great for systems with continuous data streams or fast-changing patterns (e.g. stock prices, health, finance)
- When to use? - When there is a concept drift (nature of problem changes)
- **Learning rate should be adjusted or model will forget old stuff.**


### Out of core learning

The huge dataset is broken into smaller datasets and the model is trained online with those small datasets. This is how we can train a model with huge data.
