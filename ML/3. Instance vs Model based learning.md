### Instance-Based Learning

The system **memorizes the training examples** and generalizes by comparing new data points to the stored ones using some similarity/distance measure. 

- The model doesn't learn
- Large storage as we need to data pts
- ex- KNN

### Model-Based Learning

The system builds a **generalized model** (a mathematical function) from the training data, and uses that model to predict.

- Data pts are not required
- Less storage
- Ex- Linear, logistic regression, decision trees
