## Features of functional programming language

1. All procedures are functions; incoming values (parameters) are clearly separated from outgoing values (results).
2. Once a variable is bound to a value, it behaves like a constant. Data is immutable.
3. Loops need a control variable that changes, so repetition is expressed by recursion.
4. A function’s value depends only on its arguments, not on evaluation order or the path that led to the call.
5. Functions are values: passed as arguments, returned as results, stored in data structures.
6. Pure functions do not modify globals, their arguments, or perform hidden I/O.

#### Tail recursion

A call is a tail call if it is the last thing the function does. A function is tail recursive when no computation follows any of its recursive calls.

```python
def factorial_tail(n: int, accumulator: int = 1) -> int:
    if n <= 1:
        return accumulator
    # The recursive call is the exact last operation
    return factorial_tail(n - 1, n * accumulator)


print(factorial_tail(5))  # Output: 120
```

```python
def fibonacci_tail(n: int, a: int = 0, b: int = 1) -> int:
    if n == 0:
        return a
    if n == 1:
        return b
    # State is updated in the arguments; no pending operations remain
    return fibonacci_tail(n - 1, b, a + b)


print(fibonacci_tail(10))  # Output: 55
```

### Higher order functions

A function that takes functions as parameters, returns a function as its result, or both. Also called a functional form.

One of the essential operations on functions is composition. Composition is itself a function that takes two functions as parameters and produces another function as its returned value.

Mathematically, the composition operator "$\circ$" is defined as follows: If $f: X \to Y$ and $g: Y \to Z$, then $g \circ f: X \to Z$ is given by

$$(g \circ f)(x) = g(f(x)).$$

### Lazy evaluation

#### Applicative order

All arguments are evaluated before the call. Used by Scheme, ML, C, Python, Java. Simpler to implement and usually faster.

#### Normal order

An argument is evaluated only when used, like Algol 60 pass by name. Terminates whenever any order does.
