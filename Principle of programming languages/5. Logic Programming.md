
## Features of declarative languages

1. A program is a set of logical statements (axioms). Facts and rules state what is true, not steps to execute.
2. Running a program means proving a query from the axioms by an automatic inference rule (resolution).
3. No loops or explicit sequencing in pure logic. The system supplies control: algorithm = logic + control.
4. Variables stand for unknown values and are bound once by unification. There is no assignment.
5. Arguments are not fixed as input or output. append can join lists or split them.
6. The system searches for every answer with backtracking. It treats anything unprovable as false (closed world).

### Vocabulary / Parts of first order predicate calculus

1. **Constants**: These are usually numbers or names. Sometimes they are called atoms, since they cannot be broken down into subparts. In above example 1, 0 is a constant.

2. **Predicates**: These are names for functions that are true or false, like Boolean functions in a program. Predicates can take a number of arguments. In above example, the predicate natural takes one argument.

3. **Functions**: First-order predicate calculus distinguishes between functions that are true or false. These are predicates.

4. **Variables**: That Stand for as yet Unspecified Quantities. In above example, x is a variable.

5. **Connectives**: These include the operations and, or, and not, just like the operations on Boolean data in programming languages. Additional connectives in predicate calculus are implication, signified by →, and equivalence, indicated by ↔. a → b means that b is true whenever a is true. Also a ↔ b means the same as (a → b) and (b → a).

6. **Quantifiers:** These are operations that introduce variables. In above example, **for all** is the quantifier for x; it is called the universal quantifier. There is also the existential quantifier, **there exists**, as in the following statement: there exists x, natural(x). This statement means that there exists an x such that x is a natural number. A variable introduced by a quantifier is said to be bound by the quantifier. It is possible for variables also to be free, that is, not bound by any quantifier.

7. Punctuation Symbols. These include left and right parentheses, the comma, and the period. Parentheses are used to enclose arguments and also to group operations.
