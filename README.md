
This repository contains notes about several topics I'm currently studying / have covered as a CSE student at Jadavpur University. 

Note that not all of the topics which I have made notes about are taught as part of the curriculum at this university. Most of the topics you will see covered are mainly related to my own personal interest. 

These notes do not replace a course / tutorial on any topic. It's always better if you know at least a little about what you're reading about. I would recommend these notes for revision and maybe interview prep (some of the notes may go a little too deep for interview level questions).



This repository is updated almost regularly. Mainly LLMs, blogs from several sites, YT videos, course materials and books have been used to construct the content in the notes. 

You may find references to some of these blogs, articles, etc. in some of the markdown files. If a file has no references, that simply means I haven't added them yet.


To clone the repo:

```bash
git clone https://github.com/rawmeat21/CSENotes.git
```

All of the files use markdown format, so you use software like Notion or Obsidian for best experience. I personally like Obsidian. 

To see new updated notes, do a pull:

```bash
git pull
```

If you want to view the notes on your mobile device, you can use an app like Termux to run the commands.
